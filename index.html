1. عن المشروع

يحاكي هذا النموذج خمس طبقات مقترحة لواجهات منظومة بنك المعلومات البيئية، ويهدف إلى تقديم تصور بصري وتفاعلي أولي لآليات جمع البيانات البيئية وإدارتها وتحليلها وإتاحتها للجهات المعنية والمواطنين.

يندرج البروتوتايب ضمن أعمال دراسة واقع البيانات البيئية وقواعد البيانات الحالية، واستكشاف فرص تطوير منظومة رقمية أكثر تكاملاً لدعم إدارة المعلومات البيئية.

⚠️ ملاحظة مهمة

هذا بروتوتايب مفهومي (Concept Prototype) لغرض العرض والنقاش فقط، وليس نظاماً إنتاجياً جاهزاً للاستخدام الفعلي.

2. طبقات المنظومة المقترحة

يتضمن النموذج خمس طبقات رئيسية، تمثل وظائف مقترحة ضمن منظومة بنك المعلومات البيئية:

الطبقة 01

الإدخال الميداني

عرض الاستمارات الرقمية الحالية عبر KoboToolbox، مبوّبة حسب المديرية، بما يدعم تصور آلية جمع البيانات البيئية من مصادرها.

الطبقة 02

إدارة البيانات

واجهة مقترحة لإدارة السجلات البيئية بأسلوب ويب، كتصور بديل عن الاعتماد على أدوات مكتبية معقدة في إدارة البيانات.

الطبقة 03

لوحة القيادة GIS

خريطة تخطيطية تفاعلية لمحافظات سوريا، تعرض حالة استثمار كل محافظة: نشط، محدود، أو غير مستثمَر.

الطبقة 04

تطبيق المواطن

نموذج مبسّط لواجهة عامة تتيح للمواطن الاطلاع على معلومات حالة جودة الهواء.

الطبقة 05

الإنذار المبكر

تصور لواجهة تغذية إشعارات بمستويات خطورة مختلفة، بهدف توضيح آلية عرض التنبيهات البيئية المحتملة.

3. الهدف من النموذج

يهدف البروتوتايب إلى تسهيل عرض ومناقشة تصور أولي لمنظومة بنك المعلومات البيئية، وإظهار مجموعة من الواجهات والوظائف التي يمكن دراستها ضمن مراحل التطوير اللاحقة.

  • توضيح التصور المقترح لواجهات المنظومة.
  • عرض مجالات جمع البيانات وإدارتها وتحليلها.
  • تسهيل النقاش الفني حول تطوير قاعدة البيانات.
  • دعم دراسة فرص التكامل بين البيانات والواجهات.

4. حدود النموذج وملاحظات البيانات

يجب قراءة المخرجات المعروضة ضمن حدود النموذج التصوّري، وعدم التعامل معها باعتبارها بيانات تشغيلية أو نتائج رصد آنية.

  • الأرقام والإحصاءات المعروضة افتراضية بالكامل، ولا يوجد اتصال بقاعدة بيانات حقيقية.
  • حالات المحافظات بالخريطة (نشط / محدود / غير مستثمَر) موثّقة استناداً إلى تقرير وضع المرصد البيئي.
  • لا يحتوي النموذج على نظام صلاحيات أو مصادقة مستخدمين.
  • الواجهات المعروضة توضيحية، ولا تمثل نظاماً إنتاجياً معتمداً.
تنويه بشأن الاستخدام

لا يُستخدم النموذج لاتخاذ قرارات تشغيلية أو إصدار أحكام فعلية حول الحالة البيئية، إذ يتطلب ذلك بيانات معتمدة وتكاملاً تقنياً مع مصادر البيانات المختصة.

5. التقنيات المستخدمة

تم بناء البروتوتايب كملف HTML مستقل، دون الاعتماد على إطار عمل برمجي.

HTML CSS JavaScript Chart.js SVG Map
  • Chart.js لعرض الرسوم البيانية.
  • خريطة SVG تخطيطية مرسومة يدوياً، دون اعتماد على خرائط خارجية.
  • خط Tajawal من Google Fonts.
  • لا يتطلب النموذج خادماً خلفياً (Backend) لتشغيل الواجهة التجريبية.

6. الوثائق المرتبطة بالمشروع

يشكّل هذا البروتوتايب جزءاً من حزمة توثيق أوسع تتناول واقع البيانات البيئية ومتطلبات تطوير قاعدة البيانات، وتشمل:

  • مصفوفة الربط
    الربط بين الاستمارات الحالية وقاعدة البيانات البيئية السابقة.
    تنزيل مصفوفة ربط الاستمارات بقاعدة البيانات
  • قاموس البيانات
    توثيق تفصيلي للحقول المتطابقة بين مصادر البيانات.
    تنزيل قاموس البيانات
  • دليل البيانات الأولي
    المجالات البيئية الجديدة كلياً التي تتطلب إدراجها ضمن قاعدة البيانات.
    تنزيل دليل البيانات الجديدة
  • مذكرة التوصية الفنية
    توصيات أولية لتطوير قاعدة البيانات البيئية.
    تنزيل مذكرة التوصية الفنية
